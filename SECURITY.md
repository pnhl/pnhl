## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability within Camera Gold, please follow these steps:

### 📧 Private Disclosure

1. **DO NOT** create a public GitHub issue
2. Email us directly at: **security@cameragold.app**
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Your contact information

### 🔒 What to Expect

- **Acknowledgment**: We'll acknowledge receipt within 24 hours
- **Assessment**: Initial assessment within 72 hours
- **Updates**: Regular updates on our progress
- **Resolution**: Target resolution within 30 days for critical issues

### 🛡️ Security Measures

Our app implements:
- Secure data transmission (HTTPS)
- Local data encryption
- Permission-based access control
- Regular security audits
- Dependency vulnerability scanning

### 🏆 Responsible Disclosure

We believe in responsible disclosure and will:
- Credit security researchers (with permission)
- Provide updates on fix timeline
- Release security patches promptly
- Maintain transparent communication

### 📱 User Security Tips

- Download APK only from official sources
- Keep the app updated to latest version
- Review app permissions before installation
- Report suspicious behavior immediately
